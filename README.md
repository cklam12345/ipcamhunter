# IPCamHunter 🔍

A lightweight Python and Bash toolkit designed to discover **Z-IOT** and similar cheap China OEM cameras on a local network without needing bulky ONVIF software.

## 🚀 Features
- **Fast Port Scanning:** Targets Port `554` (RTSP) and Port `8000/8899` (ONVIF).
- **No Dependencies:** Uses standard Python libraries (`socket`, `threading`).
- **OEM Focused:** Tailored for Z-IOT, YsxLite, and generic RTSP cams.
